# 沉浸式显影与手账重构设计

## 目标

解决当前扫沙交互无响应、显影边缘生硬、缺少飞沙反馈，以及手账编辑器无法形成完整体验的问题。重构后，用户能够通过具备颗粒反馈和柔边轨迹的清扫动作显影校园，并在移动端单页活页手账中自动生成、继续编辑和导出校园回忆。

## 设计原则

- 保留“扫去尘沙，唤醒校园”的核心叙事，让动作、反馈与结果形成连续体验。
- 延续项目当前米白、粉棕、纸张和手绘插画风格，不引入与视觉语言冲突的通用组件。
- 继续使用零依赖静态 Web 技术，保证 GitHub Pages 部署和现场演示稳定。
- 优先服务移动端竖屏交互，桌面端维持居中的移动设备画布。
- 重构仅覆盖显影与手账相关代码，不改动地点数据、筛选和目标路线能力。

## 扫沙显影

### 交互流程

1. 用户点击未解锁区域，立即打开显影弹窗。
2. 弹窗中的彩色地图被一层沙化 Canvas 覆盖，扫帚停留在可操作区域内。
3. 用户按下并拖动后，柔边笔刷擦除沙层，扫帚跟随轨迹并略微朝移动方向旋转。
4. 每次有效移动从扫帚后方喷出飞沙颗粒；颗粒具有随机大小、惯性、旋转、扩散和渐隐。
5. 进度达到 60% 后完成显影，弹窗关闭，地图聚焦到新区域并显示柔边彩色区域。

### 输入状态

清扫状态由统一的 Pointer Events 状态机管理：

- `pointerdown`：开始清扫、捕获指针并记录起点。
- `pointermove`：仅在清扫状态下擦除、更新扫帚与产生颗粒。
- `pointerup`、`pointercancel`、`lostpointercapture`：统一结束清扫并清空上次轨迹点。
- 弹窗关闭和重新打开时强制重置清扫状态，避免残留状态导致无响应。

地图区域按钮与地图拖拽继续使用 Pointer Events，但通过目标元素判断隔离，不得吞掉区域点击。

### 柔边擦除

沙层擦除采用 Canvas 径向渐变笔刷，而不是固定硬边线条：

- 核心区域完全透明。
- 中间区域逐渐降低透明度。
- 外围保留轻微沙雾，避免轨迹像圆形橡皮擦。
- 快速移动时在前后点之间插值绘制，保证轨迹连续。

### 飞沙粒子

显影弹窗增加独立粒子 Canvas，覆盖于沙层之上、扫帚之下或附近。粒子系统只在清扫时运行：

- 每次移动按距离产生有限数量颗粒。
- 颗粒颜色取暖沙色与淡金色，透明度随生命周期下降。
- 速度包含移动方向的反向惯性与随机扩散。
- 粒子离开画布或生命周期结束后回收。
- 尊重 `prefers-reduced-motion`，减少粒子数量和动画强度。

### 地图区域柔边显影

每个区域使用 `regions[].polygon` 作为真实轮廓。渲染时生成两层相同区域：

- 内层：裁切到区域轮廓，显示完整彩色地图。
- 外层：使用 SVG/CSS 滤镜扩散轮廓并降低透明度，形成从彩色到沙化地图的渐变过渡。

区域完成显影时执行短暂的饱和度与透明度过渡。多个已解锁区域的柔边可以自然重叠；全部解锁时直接显示完整彩色地图。

## 移动端单页手账

### 页面结构

手账页面改为沉浸式编辑界面：

- 顶部：标题“我的手账本”、日期与返回按钮。
- 中部：单页竖向活页手账，占据主要屏幕空间。
- 左侧：装订环与纸页阴影，建立真实手账本质感。
- 画布：米白网格纸、轻微纹理、胶带和花朵等固定装饰。
- 底部：固定工具栏，入口为贴纸、文字、照片、地点、导出。
- 工具栏上方：按需展开的素材抽屉。
- 选中元素附近：轻量浮动操作条，提供编辑、缩放、旋转、层级与删除。

### 自动生成校园回忆

首次进入且没有用户手账数据时，根据已显影地点生成一页内容：

- 日期贴纸和“今日校园漫游”标题。
- 最多三个已发现地点卡片，优先选择代表性分数高的地点。
- 一段根据显影数量生成的短文。
- 建筑、植物、胶带或便签装饰，使页面首次打开即具备完成度。

自动生成内容此后与普通元素一致，可被用户移动、编辑或删除。若尚未显影任何区域，则生成轻量引导页，提示用户先探索校园。

### 贴纸素材

直接使用用户提供的整套贴纸平面设计图作为视觉来源，从中切分首批代表性透明素材：

- 建筑贴纸
- 人物与雕塑贴纸
- 植物与花朵贴纸
- 胶带贴纸
- 文字与标签贴纸
- 便签与纸张贴纸
- 相框贴纸
- 小图标贴纸

首版不要求切分图中的每一个小元素，但每个分类至少提供一组可实际使用的素材。素材切片存放于 `assets/journal-stickers/`，并由独立清单描述分类、名称、文件路径和默认尺寸。

### 编辑能力

手账元素继续使用 DOM 渲染，以便移动端选择与拖动：

- 拖动：元素在纸张范围内移动。
- 缩放与旋转：通过浮动操作条调整。
- 层级：支持置顶和下移。
- 文字：支持新增和再次编辑。
- 照片：通过本地文件选择添加，并以拍立得样式显示。
- 地点：从已发现地点抽屉中添加。
- 贴纸：从分类素材抽屉中添加。
- 删除：删除当前选中元素。

点击画布空白处取消选择。拖动结束后保存数据，避免每帧写入 `localStorage`。

### 持久化与兼容

- 使用新的版本化存储键，例如 `yuditu:journal:v2`。
- 首次加载时若发现旧版 `yuditu:journal` 数据，转换为新版通用元素结构。
- 图片较大导致存储失败时，保留当前编辑状态并显示明确提示。
- 清空操作需要用户确认，清空后重新生成空白引导页，而不是立刻恢复默认内容。

### PNG 导出

Canvas 导出需要还原手账纸张、固定装饰和用户元素：

- 导出尺寸保持竖向单页比例。
- 贴纸与照片按实际层级、旋转和缩放绘制。
- 不导出编辑选中框、浮动操作条和素材抽屉。
- 优先调用系统分享；不可用时下载 PNG。

## 代码边界

为避免继续扩大 `src/app.mjs`，新增两个聚焦模块：

- `src/reveal.mjs`：柔边笔刷、粒子状态与区域显影辅助逻辑。
- `src/journal.mjs`：手账默认生成、素材清单处理、版本迁移和导出辅助逻辑。

`src/app.mjs` 负责 DOM 事件连接和页面状态，不再承载所有算法细节。

## 错误与降级

- 不支持 `filter` 或复杂蒙版的浏览器仍显示可用的较宽径向柔边。
- `prefers-reduced-motion` 下粒子数量明显减少，但清扫轨迹和进度保持可用。
- 图片读取失败时不添加损坏元素，并提示用户重新选择。
- 导出单个贴纸资源失败时跳过该元素并提示，而不是阻塞整个手账。

## 测试与验收

### 自动化测试

- 清扫状态在 `pointerup`、`pointercancel` 和 `lostpointercapture` 后都能正确结束。
- 柔边笔刷生成具有核心、过渡与外围的渐变参数。
- 粒子数量受上限控制，生命周期结束后会回收。
- 区域显影使用 `polygon` 轮廓并包含柔边层。
- 首次手账根据已显影地点自动生成代表性地点内容。
- 旧版手账数据可以迁移到新版结构。
- 手账页面包含底部工具栏、素材抽屉和浮动操作条。
- PNG 导出包含纸张、贴纸、地点、文字和照片元素。

### 浏览器验收

- 未解锁区域点击一次即可打开显影弹窗。
- 鼠标和触控拖动均能持续擦除，移出或取消后再次拖动仍正常。
- 清扫过程中可以清楚看到飞沙，且不卡顿。
- 显影区域边缘不存在明显硬切线。
- 手账首次打开即有完成度，视觉接近用户提供的纸质手账与贴纸参考。
- 用户可以从底部抽屉添加贴纸、文字、照片和地点。
- 元素可拖动、缩放、旋转、调整层级和删除。
- 刷新页面后手账内容仍存在，导出图片与编辑画布视觉一致。
