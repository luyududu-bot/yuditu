# 路线专注模式、视觉校准与对象 Action 最小闭环设计

## 目标

在不重构现有零依赖静态 Web 架构的前提下，优先加强屿地图的核心演示链路：

1. 让目标推荐真正形成一条清晰、可解释、可浏览的路线。
2. 修复设施类图标的视觉中心错位。
3. 将区域显影边缘改为自然扩散的沙雾过渡。
4. 让结构化对象的 `actions` 从展示字段变为可调用能力。

## 范围与原则

- 路线只从已显影区域中的地点生成。
- 生成路线后自动进入路线专注模式。
- 保留现有 DOM 地图、原生 JavaScript、CSS 和 SVG/Canvas 混合实现。
- 不在本轮重构手账编辑器，不引入外部依赖。
- 保持普通探索、区域显影和地点详情的现有主流程。

## 路线专注模式

### 路线候选与排序

路线规划先过滤出已显影地点，再综合以下因素排序和串联：

- 用户目标标签、兴趣与需求的匹配度。
- 地点的 `representativeScore`。
- 地点访问时间与用户时间预算。
- 候选地点之间的地图坐标距离，优先减少明显折返。

路线最多包含四个地点。系统先选择目标匹配度最高的首站，再在剩余候选中兼顾匹配度和与上一站的距离。

每个路线站点返回独立推荐理由，包括目标匹配标签、代表性和顺路关系。路线结果同时返回总预计时间。

### 地图表现

生成路线后：

- 自动计算全部路线站点的坐标边界，并将地图聚焦到能容纳整条路线的范围。
- 隐藏非路线地点和区域按钮，降低视觉干扰。
- 路线地点显示 `1、2、3…` 顺序徽标。
- 使用覆盖地图的 SVG 绘制柔和曲线路径，连接经过视觉锚点校准的地点中心。
- 路线结果卡展示时间、站点顺序、逐站推荐理由和“退出路线”命令。

退出路线后恢复普通地图视图、区域按钮和当前分类筛选结果。

## 图标视觉锚点

地点对象的地图坐标继续表示地标在地图中的逻辑位置。设施图标因素材本身存在不对称外形，需要通过类别级视觉锚点校准图标外形中心。

为使用图形素材的类别配置：

```js
{
  补给: { anchorX: 0.50, anchorY: 0.58 },
  打卡: { anchorX: 0.50, anchorY: 0.54 },
  出入口: { anchorX: 0.50, anchorY: 0.60 },
  服务: { anchorX: 0.50, anchorY: 0.56 },
  展览: { anchorX: 0.50, anchorY: 0.57 }
}
```

锚点使用相对于图标边界的归一化坐标，`0.5 / 0.5` 表示几何中心。初始值作为校准起点，浏览器验收时按实际素材外形微调。锚点通过 CSS 自定义属性或渲染后的坐标偏移应用。建筑编号标记保持默认居中。

以下视觉元素必须使用同一个校准后的中心：

- 图标自身。
- 路线 SVG 端点。
- 路线顺序徽标。
- 点击热区和聚焦高亮。

锚点配置集中放置，方便以后新增或重新校准素材。

## 自然沙雾显影边缘

当前单层模糊多边形仍能明显看出硬切轮廓。每个已显影区域改为由多层过渡共同构成：

1. **彩色核心层**：按区域多边形裁切，保持地图细节清晰。
2. **近缘柔化层**：轻微扩张并模糊，降低多边形边线的锐度。
3. **外缘沙雾层**：使用更宽的模糊、较低透明度和轻微位置偏移，打散规则轮廓。
4. **颗粒过渡层**：通过 CSS 噪点纹理或径向颗粒蒙版，让彩色与沙色之间形成稀疏、自然的过渡。

不同区域的沙雾层允许自然重叠。全部区域显影后直接切换到完整彩色地图，不继续展示边缘层。

显影完成动画从低饱和、低透明度状态逐渐恢复完整色彩。`prefers-reduced-motion` 下缩短或取消过渡动画。

## 对象 Action 最小闭环

新增独立对象能力模块，统一提供以下接口：

- `listObjects(filters, context)`
- `getObject(objectId)`
- `getAvailableActions(objectId, context)`
- `executeAction(actionId, objectId, context)`
- `planRoute(goal, context)`

首批可执行 action：

- `focus_on_object`
- `open_detail`
- `add_to_route`
- `create_journal`
- `set_as_start`

`getAvailableActions` 根据对象声明的 `actions` 和当前显影状态返回能力。需要区域显影的对象在未显影时不可执行详情、聚焦、路线和手账操作。

详情弹窗展示真实 action 按钮。按钮调用统一执行器，再由 `src/app.mjs` 提供聚焦地图、打开详情和写入手账等界面适配函数。

## 数据校验

增加可独立测试的数据校验函数，检查：

- 地点和区域 ID 是否重复。
- `regionId` 是否引用真实区域。
- `relations` 是否引用真实对象或明确允许的外部 ID。
- `actions` 是否属于受支持 action 列表。
- 路线必需元数据是否存在并为有效值。

现有无效关系引用应在本轮修复或显式登记为外部对象，不允许静默保留悬空引用。

## 代码边界

- `src/core.mjs`：目标解析、路线候选评分、距离排序和路线结果。
- `src/object-actions.mjs`：对象查询、action 可用性、执行分发和数据校验。
- `src/app.mjs`：DOM 状态连接、路线专注模式、地图聚焦与 action UI 适配。
- `src/data.mjs`：地点数据、支持的关系数据和视觉锚点配置。
- `styles.css`：路线、锚点偏移、顺序徽标和多层沙雾样式。

## 错误与降级

- 已显影地点不足时返回可用地点，并明确说明结果数量有限。
- 没有任何已显影地点时不生成路线，提示用户先完成显影。
- 路线 SVG 不可用时仍保留顺序徽标和路线结果列表。
- 不支持复杂 CSS 蒙版时保留多层模糊边缘，显影功能仍可使用。
- action 不可用时按钮禁用，并提供简短原因。

## 测试与验收

### 自动化测试

- 路线只包含已显影地点。
- 路线不超过时间预算，并减少明显折返。
- 每个路线站点包含推荐理由。
- 图标类别均存在有效视觉锚点。
- 路线 SVG 和顺序徽标使用校准后的中心。
- 未显影对象的受限 action 不可用。
- action 执行器分发到正确适配器。
- 数据校验能够发现悬空关系、重复 ID 和未知 action。
- 显影区域输出核心、近缘、沙雾和颗粒层。

### 浏览器验收

- 生成路线后自动聚焦并隐藏无关地点。
- 路线顺序、连线和结果卡可清晰理解，退出后恢复普通探索。
- 设施图标外形中心与地点坐标对齐，路线端点也与外形中心一致。
- 显影边缘不再呈现明显直线或规则多边形切边，而是自然沙雾扩散。
- 地点详情中的 action 按钮能够真实触发聚焦、路线和手账操作。
