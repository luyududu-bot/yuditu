# 屿地图

> AI 时代，连接空间、展览与记忆，让每一次校园探索都值得被珍藏。

屿地图是一款面向中央美术学院花家地校区的移动端视觉探索图鉴。用户通过清扫尘沙逐步显影校园，在发现建筑、展览、服务与文化地标的同时，也能根据时间和兴趣生成一条可解释的探索路线，并将旅程制作成 DIY 校园手账。

## 核心体验

| 显影探索 | 目标路线 | DIY 手账 |
| --- | --- | --- |
| 清扫尘沙，按任意顺序显影四片校园区域。 | 表达时间与兴趣，生成带逐站理由的探索路线。 | 添加地点、贴纸、文字与照片，自由排版并导出 PNG。 |

### 探索校园

- 区域沿真实地图轮廓局部显色，并通过柔边、薄雾和飞沙颗粒自然融入地图。
- 建筑采用校园编号，展览、服务、补给、打卡与出入口采用定制透明图标。
- 地点显影后可查看详情、加入路线、写入手账或设置为路线起点。
- 支持地图拖动、缩放和按类别筛选，北门、东门与南门均已标注。

### 组织路线

- 用户可表达“我第一次来，只有 20 分钟，想看最有代表性的地方”等目标。
- 本地目标解析器综合已显影地点的语义、代表性、访问时间与空间距离生成路线。
- 路线包含逐站推荐理由，并以顺序节点和 SVG 曲线路径进入专注展示。

### 珍藏记忆

- 手账会根据已经发现的地点自动生成校园回忆。
- 用户可添加独立贴纸、地点、文字和照片，并自由拖动、缩放、旋转与调整层级。
- 完成后的手账可导出为 PNG，用于保存或分享。

## AI Native 设计

屿地图没有把 AI 做成附加聊天框，而是先把校园转化为可理解、可组合、可调用的对象系统。每个地点均包含：

- `type`、`category` 与 `tags`
- `relations`
- `actions`
- `constraints`
- `metadata`

当前版本使用本地目标解析与路线推荐验证 goal-based 交互，不依赖模型 API。项目已经提供对象查询、action 权限过滤、执行分发与数据关系校验的最小闭环，为未来接入平台级 Agent 保留稳定接口。

## 项目状态

- 移动端优先的交互原型，推荐使用手机或窄屏浏览器体验。
- 当前地图内容对应中央美术学院花家地校区。
- 项目没有后端服务；显影进度与手账排版保存在浏览器 `localStorage`。
- 视觉地图、贴纸与图标为项目定制素材。

## 本地运行

需要 Node.js。项目使用零依赖静态 Web 技术，无需安装第三方包。

```bash
npm start
```

访问 `http://localhost:4173`。

运行测试：

```bash
npm test
```

## 项目结构

```text
src/data.mjs            校园区域、地点对象与视觉锚点
src/core.mjs            目标解析与路线推荐
src/object-actions.mjs  对象查询、权限、action 分发与校验
src/reveal.mjs          局部显影与清扫交互
src/journal.mjs         手账数据与排版逻辑
assets/                 地图、图标与贴纸素材
```

## 商业逻辑

屿地图以学校、展览主办方和文化园区为服务对象，提供定制化视觉导览与内容运营服务；访客免费使用。对象系统和目标路线能力可复制到其他艺术院校、博物馆与文化园区，手账分享、限定贴纸和联名文创则承担传播与增值。
